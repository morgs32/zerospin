## Original source audit — before Plan 231

The following sections record the sixteen-column model and stale snapshot-consumer observation at review time. Current implementation is summarized above and below.

### Physical scope, row meaning and lifetime

[aggregateNodeCommands](../../../packages/core/src/AggregateNode/aggregateNodeTables.ts#L22-L56) declares the physical SQL table commands. AggregateNode owns its retained local delivery journal, selected resources and producer/checkpoint metadata within one persistent database generation. One row is an immutable original-admission or final-exposure record, not mutable pending command state and not an audit/telemetry record.

1. A new original receives a local nodeIndex and producer pushIndex when AggregateNode.accept commits its input. This is Node retention, distinct from later AggregateChain admission and authoritative execution. Exact original retries return the same retained original and any final; they do not allocate again. [Original admission and comparison](../../../packages/core/src/AggregateNode/acceptAggregateOriginalTx.ts#L35-L121).
2. Final exposure receives a separate nodeIndex and authoritative aggregateIndex. It may correspond to this producer's original or be final-only history from another producer. Retention compares exact duplicate exposure, checks occupied position/name/continuity, applies selected resource changes and advances checkpoint/admission proof in one transaction. [Final retention](../../../packages/core/src/AggregateNode/retainAggregateFinalTx.ts#L32-L131).
3. Connected browser SharedWorkers persist through IndexedDB-backed SQLite; standalone browser uses the authored scope/path address with a separately retained owner/lock binding; Native uses the identity-keyed Node file. Reopen/reconnect preserves this generation's journal. A standalone attachment may have different valid claims while sharing the same path/owner. [Browser ownership](../../../packages/browser/src/AggregateNode/makeAggregateSharedWorker.ts#L9-L25), [standalone identity and retained binding](../../../packages/browser/src/StandaloneNode/makeStandaloneWorkerRuntime.ts#L116-L129), [standalone per-command validation](../../../packages/browser/src/StandaloneNode/makeStandaloneWorkerRuntime.ts#L173-L205), [Native owner](../../../packages/native/src/openAggregateNativeNodeOwner.ts#L30-L55).
4. Admission acknowledgement and subscription acknowledgement never delete these rows. Closing a host closes storage after draining admitted work; it does not prune history. Only whole-generation replacement clears commands with resources/checkpoint replacement and a new nodeId. Derivation of allocator maxima and the private final prefix depends on this retained generation history; no individual deletion/compaction is introduced. [Replacement transaction](../../../packages/core/src/AggregateNode/AggregateNode.ts#L798-L827), [delivery acknowledgement](../../../packages/core/src/Node/makeNodeSubscriptions.ts#L103-L117).

### Every current column and constraint

There are sixteen declared columns. nodeIndex is the integer primary key; id and commandName are required text. The thirteen others are nullable, representing phase-specific absence. There are no declared defaults, foreign keys, expiry, extra timestamps or phase CHECK constraints. In addition to the primary key, pushIndex and aggregateIndex each have nullable uniqueness, and partial unique indexes enforce one original ID where pushIndex is present and one final ID where aggregateIndex is present. A command ID is intentionally not globally unique across both phases.

### Structured members and null meaning

1. **Current origin:** schema variants are Actor `{ kind, actorName, actorVersion, claims }` and Agent `{ kind, agentName, agentVersion }`; AggregateNode supports the Actor variant here. Keep complete command-specific encoded claims as the proposed claims column, including an empty record. Connected originals still require bound authenticated claims equality; standalone still validates its authored claims schema and executes using the retained original claims. Do not replace those claims with a hash, current provider value or metadata's first attachment claims. [Origin schema](../../../packages/core/src/contracts/OriginSchema.ts#L3-L14), [connected claim comparison](../../../packages/core/src/AggregateNode/acceptAggregateOriginalTx.ts#L83-L95), [standalone execution claims](../../../packages/browser/src/StandaloneNode/executeStandaloneCommand.ts#L64-L68).
2. **stagingOutcome:** result is the encoded authored result JSON, not a Success/Failure wrapper. completedAt is the encoded date string. Failed local staging creates no original. The Node sends neither this value nor its result to AggregateChain; it retains the original local fact for local history and exact recovery. Replica import compares the whole value, and replay uses its original completedAt while replacing current inverseOperations independently. [Compact schema](../../../packages/core/src/contracts/StagingOutcomeSchema.ts#L3-L7), [local retention](../../../packages/core/src/aggregateSession/stageCommand/stageAggregateSessionCommandTx/stageAggregateSessionCommandTx.ts#L28-L45), [original equality](../../../packages/core/src/aggregateSession/applyOrderedAggregateOccurrencesTx.ts#L177-L194), [replay time](../../../packages/core/src/aggregateSession/replayPendingCommandsTx.ts#L88-L104), [outbound admitted-command fields](../../../packages/browser/src/AggregateNode/AggregateNodeSynchronization.ts#L613-L658).
3. **failure:** a present object has `_tag: 'ZerospinError'`, code, optional scope (`contract`, `actor` or `aggregate`), message, nullable status and full extra JSON. Preserve this declared public representation, not local recognition metadata. [Failure schema](../../../packages/error/src/matchZerospinErrorCode.ts#L27-L36).
4. **delta / proposed exposedDelta:** upserted contains complete selected resource images; deleted contains `{ id, modelName }` references. Each resource image carries id/modelName/version/createdAt/updatedAt and authored attributes. Their complete declared nested values are needed for exact history and replica application, not separate operation storage. An empty delta is a valid final and still advances final progress. The proposed original requires nodeIndex/id/commandName plus positive pushIndex and present payload/claims/stagingOutcome; its final position/hash/exposedDelta/failure are absent. The proposed final requires nodeIndex/id/commandName, positive aggregateIndex and present dispositionChainHash/exposedDelta, with nullable failure; original-only fields are absent. Require coherent phase shapes, rejecting both-phase and neither-phase rows rather than adding another discriminator. Keep all five existing key/unique constraints with their phase-specific meaning.

### Why two append rows and original retention remain

Original A can occupy nodeIndex 1/pushIndex 1, unrelated final B nodeIndex 2, original C nodeIndex 3/pushIndex 2, and final A nodeIndex 4. Both original and final are independently delivered local events. A subscriber that already acknowledged index 1 must later receive final A at index 4. Updating the original row in place under index 1 would make that final invisible to pages after 1; moving that row to index 4 would erase original history and captured coordinates.

A canonical-ID row with separate original/final Node coordinates and a reconstructed phase-union stream could preserve the same facts, but it would retain both delivery responsibilities and add query machinery. Two immutable rows directly represent the actual journal. This is a lifecycle argument, not a constraint inherited from an old ADR. The Agent replica's one-row pending-state model has a different responsibility.

Original input also remains necessary after final exposure. A tab may lose the Node handoff receipt, then reconnect after both original and final committed. pendingReceipts must return the exact original input/Node/producer positions and its optional final together. Unresolved originals and requested receipt partitions share the captured resource/checkpoint boundary. Clearing original payload/claims/stagingOutcome at exposure would destroy exact retry and recovery evidence. A final-only canonical ID cannot later acquire an unproven local original. [Captured receipt reconstruction](../../../packages/core/src/AggregateNode/AggregateNode.ts#L374-L429), [exact original retry/conflict behavior](../../../packages/core/src/AggregateNode/acceptAggregateOriginalTx.ts#L52-L76).

Subscription pages are contiguous nodeIndex records, and a receiver advances afterNodeIndex only after its transactional import. Callback completion advances the lease cursor without deleting journal rows. The original/final append and resource/checkpoint transaction boundaries, safe allocation/exact retries, current-generation fences, private correlation and full reset semantics remain requirements. [Read pages](../../../packages/core/src/AggregateNode/AggregateNode.ts#L135-L150), [contiguous import](../../../packages/core/src/aggregateSession/importAggregateNodeCommands.ts#L78-L112), [lease acknowledgement](../../../packages/core/src/Node/makeNodeSubscriptions.ts#L103-L117), [private contiguous final proof](../../../packages/core/src/AggregateNode/readAggregateNodeOutcomeIndex.ts#L8-L31).
