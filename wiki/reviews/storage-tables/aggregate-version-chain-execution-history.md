## Physical scope and lifecycle

One physical AggregateVersionChain is bound to `systemId / aggregateId / aggregateName / aggregateVersion`. It owns immutable evaluated `commands` and history-backed actor/agent delivery with independent subscriber cursors. It owns no authored model-resource tables. Source `command.aggregateVersion` records original admission routing; the bound AggregateVersionChain release identifies which release evaluated the command. Replay must preserve that distinction.

1. AggregateVersionRepo synchronously commits resources or retained Failure, its materialization head and a complete pending evaluated command. `finalizeCommand` returns that same value. Lost replies recover pending publication, then permanent history after acknowledged deletion, without re-running the program or allocating external IDs.
2. `appendEvaluatedCommands` acquires both fanout producer leases; `appendEvaluatedCommandsTx` decodes full commands, enforces increasing/contiguous positions, compares complete duplicates and inserts `commands` atomically. Both fanout queues deliver directly from `commands` with no duplicate payload insertion. Failure rolls back the batch. Full equality includes admitted input, outcome/timestamp and all operations; the disposition hash cannot replace it.
3. AggregateVersionRepo deletes acknowledged pending publication only after AggregateVersionChain retention. Actor or agent acknowledgement advances only the corresponding subscriber cursor after AggregateActorVersionRepo or AggregateAgentVersionRepo commits resources, progress and complete pending selected publication; it does not establish publication to that projection's Chain. No acknowledgement deletes `commands`.
4. `getEvaluatedCommand`, bounded command pages and both fanout queues read immutable `commands`. Exact recovery, late projection catch-up and enrollment therefore survive source publication deletion; retained commands cover the catch-up/enrollment interval. There is no production history update/delete/prune path or separate historical checkpoint RPC in AggregateVersionChain.

## Every current column

All fields are immutable after append. The producer tuple is all null or all present. `externalOutcome` is independently nullable; null means ordinary input without an external observation. Framework construction adds no authored resource metadata columns.

| Column                 | Meaning and retention rationale                                                                                                                                                                                                         |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `aggregateIndex`       | Positive primary-key position in admitted Aggregate order. Supports contiguous history, pages, catch-up, recovery and hash advancement.                                                                                                 |
| `id`                   | Unique canonical admitted command identity. Replaces the publication-only `commandId` conversion and supplies operation lineage/application identity.                                                                                   |
| `commandName`          | Exact admitted contract name; retained input association, result recovery and projected command identity.                                                                                                                               |
| `payload`              | Complete encoded admitted payload. Full command retention is approved; current resources or output cannot recreate it.                                                                                                                  |
| `externalOutcome`      | Nullable recorded external observation from the admitted command, including its own `recordedAt`. It is input to continuation evaluation, distinct from the resulting command outcome.                                                  |
| `contractVersion`      | Admitted contract provenance, preserved across different evaluating releases.                                                                                                                                                           |
| `aggregateId`          | Original Aggregate instance identity. Explicit full-command context remains available in returned/history values despite matching the bound owner.                                                                                      |
| `aggregateName`        | Original Aggregate declaration name. Full input validation and projection binding verify owner association.                                                                                                                             |
| `aggregateVersion`     | Original admission release. Replay does not overwrite it with the evaluating release; the latter comes from the bound owner.                                                                                                            |
| `origin`               | Complete Actor/Agent/System authority, independent of nullable producer context. Preserves exact identity filtering and external request provenance.                                                                                    |
| `nodeId`               | Nullable submitting Node, coupled to sessionName/pushIndex for private completion. Null is not System authority.                                                                                                                        |
| `sessionName`          | Nullable submitting session declaration, coupled to producer tuple; needed for exact private completion association.                                                                                                                    |
| `pushIndex`            | Nullable producer submission position, coupled to producer tuple. Aggregate position cannot replace a producer-local sequence.                                                                                                          |
| `outcome`              | Non-null `{ result: Success \| Failure, finalizedAt }`. Retains exact encoded success/public failure and the one finalization sample for recovery, application and projection.                                                          |
| `dispositionChainHash` | Release-local prefix over previous hash, position, command ID and `outcome.result._tag`. Retain it at every historical position; a current head cannot replace old values.                                                              |
| `operations`           | Non-null authored-order union of model mutations and frozen external descriptions. Failure is empty; replay may retain sparse model indexes. Current resources cannot reconstruct historical mutations or frozen external IDs/payloads. |

The full admitted fields deliberately replace the earlier normalization of top-level owner/input context. The maintainer approved one complete evaluated-command value across construction, return, pending delivery and permanent history. This is distinct from removing four repetitions inside each embedded operation.

## Structured values and output semantics

1. Origin remains Actor `{ kind: 'actor', actorName, actorVersion, claims }`, Agent `{ kind: 'agent', agentName, agentVersion }`, or System `{ kind: 'system' }`. Authored claims may contain null values; a null producer tuple says nothing about Origin authority.
2. `outcome.result` is `{ _tag: 'Success', success }` or `{ _tag: 'Failure', failure }`, with existing JSON/public failure codecs. `outcome.finalizedAt` is beside result, outside both branches. Explicit null success is valid. Exact duplicates preserve the complete outer outcome. `externalOutcome` retains its separate branch `recordedAt` and external-request failure meaning.
3. Model members are `{ operationIndex, modelName, modelVersion, resourceId, operationName, body }`. Names/versions bind exact model codecs. Create/update/delete/move bodies preserve canonical complete/patch/empty/move semantics. Parent `id` and `outcome.finalizedAt` supply application identity/time; no inverse, per-operation timestamp or prior resource snapshot is retained here.
4. External members are `{ operationName: 'external', operationIndex, externalContractName, externalContractVersion, payload, externalCommandId }`. Parent context and bound original release reconstruct complete independently durable AggregateChain pending requests. Historical descriptions are evidence, not request backlog or permission to execute external work again.
5. Every member retains its original nonnegative safe `operationIndex`. Mixed order is not regrouped by consumer. Replay filters external emissions before preparation/ID allocation and preserves model gaps. Projection applies only model members using the source finalization sample.

## Deferred publication hash validation

The current producer computes the disposition prefix; projection checks it when applying new output. AggregateVersionChain validates hash format and full duplicate equality but does not independently recompute a new append's predecessor hash. The maintainer explicitly deferred that additional validation. No corruption was observed, and it is not required or pending implementation work in Plan 200. Full evaluated-command equality remains necessary because the digest covers only the ordered identity/disposition tuple, not input values, result details, operations or resource equality.

## Failure boundaries and verification

1. Failed source or append transactions retain no partial publication/history/fanout. Lost acknowledgements allow exact retries. A retained public Failure is a finalized command with no operations; an infrastructure failure does not create a new evaluated command.
2. After sender publication deletion, permanent history supplies the exact full command, outcome, source timestamp and frozen external IDs. No current head or AggregateChain outcome-only value substitutes for it.
3. Actor and agent acknowledgement advance separate subscriber cursors and never remove commands. Projection failures retry complete retained commands; resource/progress changes commit only together.
4. The original independent lifecycle/column review remains complete for its historical snapshot.
